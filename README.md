# Contadora-Kesia | Kesia Feitosa

Página profissional em português, responsiva, com contato pelo WhatsApp (12) 99746-2143, informado pelo usuário.

## Conteúdo e identidade

Nome, serviços e atendimento nacional foram conferidos no perfil público https://www.instagram.com/contadorakesiaaf/ em 1º de outubro de 2026. A paleta de caramelo, marrom e creme e os títulos serifados seguem as publicações observadas. Os textos de apresentação e de serviços foram redigidos para esta página. Não foram acrescentados números de registro, preços, depoimentos ou resultados de clientes.

A foto principal foi enviada pelo usuário como projetokesia.jpg e foi incorporada sem alterar o arquivo original. Seu enquadramento é definido pelo CSS da página. As demais imagens são arquivos reais do perfil fornecido pelo usuário.

## Arquivos

`dist/index.html`, `dist/styles.css` e `dist/script.js` compõem a página. As imagens estão em `dist/assets`. Não há dependências de instalação. As fontes usam o Google Fonts, com alternativas locais.

Para visualizar localmente, execute `python3 -m http.server 4173 --directory dist` nesta pasta.
