## 📖 Sobre o Projeto

Uma página web moderna, responsiva e de alta performance desenvolvida para a contadora **Kesia Feitosa**. O projeto foi criado com foco em transmitir autoridade, elegância e clareza, guiando o usuário através de uma experiência fluida até o ponto de contato pelo WhatsApp.

O design adota um estilo visual refinado ("Premium Aesthetic"), utilizando uma paleta de cores harmoniosa baseada em tons de caramelo, creme e branco ("paper"), aliados a tipografia clássica (Serif) combinada com Sans-Serif para ótima leiturabilidade.

## ✨ Principais Funcionalidades

- **Design Premium e Delicado:** Utilização de cores suaves, bordas translúcidas (RGBA) e elementos refinados para evitar uma interface pesada.
- **Header Glassmorphism:** Barra de navegação com efeito de vidro fosco (`backdrop-filter: blur`), que flutua suavemente sobre o conteúdo da página.
- **Animações e Micro-interações:**
  - Animações de entrada utilizando `IntersectionObserver` para revelar o conteúdo enquanto o usuário rola a página.
  - Efeito parallax suave nas imagens.
  - Faixa de texto contínua (Marquee) rodando em loop infinito.
- **Formulário de Pré-qualificação Integrado:** Ao invés de um simples link para o WhatsApp, um Modal interativo capta informações essenciais do cliente (nome, CNPJ e demanda) antes do redirecionamento, agilizando o atendimento.
- **Totalmente Responsivo:** Layout projetado com *Mobile First* em mente, perfeitamente adaptado para celulares, tablets e desktops (com breakpoints avançados para garantir consistência visual).

## 🛠 Tecnologias Utilizadas

Este projeto foi construído focando em performance, acessibilidade e flexibilidade, sem a sobrecarga de frameworks complexos para uma Landing Page.

- **HTML5:** Estrutura semântica e acessível (com marcações Aria onde necessário).
- **CSS3 (Vanilla):** Utilização intensiva de CSS Variables (`:root`), Flexbox, CSS Grid, clamp() para tipografia fluida e animações nativas (@keyframes).
- **JavaScript (Vanilla):** Lógica limpa para manipulação do DOM, controle do modal de WhatsApp, preenchimento dinâmico de URL de contato e IntersectionObservers.

## 🚀 Como Executar Localmente

Como se trata de um projeto construído com HTML, CSS e JS puros, não há necessidade de instalação de pacotes complexos (NPM, Yarn, etc).

1. Clone o repositório:
```bash
git clone https://github.com/lipeandrade08-coder/Contadora-Kesia.git
```

2. Acesse o diretório do projeto:
```bash
cd Contadora-Kesia
```

3. Abra o projeto usando um servidor local rápido (como Live Server no VSCode) ou via Python:
```bash
python3 -m http.server 4173 --directory dist
```

4. Acesse no seu navegador:
```text
http://localhost:4173
```
